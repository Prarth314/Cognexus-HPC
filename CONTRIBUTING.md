# Contributing

Use feature branches and pull requests; never force-push a shared branch. Fetch main before starting and before requesting merge. Preserve original team attribution.

Run `npm run check`, `npm test`, and `npm run build` before pushing. Keep credentials, private datasets, artifacts, and local databases out of Git. API routes require authorization and validation; workflows require bounded resources, deterministic fixtures, and output contracts.

Describe the problem, final behavior, tests, and remaining limitations in each PR. Do not label mock execution or unverified integration as production HPC.
